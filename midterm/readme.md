# แนวโจทย์ midterm 2568

### 1. exchangemoney
รับจำนวนแบงค์ที่มีอยู่ 5 ประเภทไล่ตามนี่ (20, 50, 100, 500, 1000) และ ประเภทแบงค์ที่จะแลกด้วย (1-5 คือแบงค์ที่จะแลกไล่ไปจากแบงค์ 20 - 1000)
และแสดงจำนวนแบงค์ที่แลกได้ออกมา ถ้ามีเศษที่เหลือให้แสดงเศษออกมาด้วย เช่น 

- มีแบงค์ 20 อยู่ 5 ใบ
- มีแบงค์ 50 อยู่ 2 ใบ
- มีแบงค์ 100 อยู่ 1 ใบ
- มีแบงค์ 500 อยู่ 0 ใบ
- มีแบงค์ 1000 อยู่ 0 ใบ

ต้องการจะแลกทั้งหมดที่กล่าวเป็นแบงค์ 20 ทั้งหมด ดังนั้นเราจะสามารถแลกแบงค์ 20 ได้ทั้งหมด 15 ใบ

### 4. sumgroup
ให้ทำการรับค่ามา เรื่อยๆจนกว่าจะเจอ 0 1 ชุดมี3จำนวนและทำการบวกจำนวนเหล่านั้นและแสดงผลบวกในแต่ล่ะรอบและเมื่อเจอ 0 เราจะทำการแสดง ชุดที่ และ ผลลัพธ์ที่บวกมากที่สุด และ น้อยที่สุดออกมาและจบโปรแกรม
